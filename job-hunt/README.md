## ข้อขัดแย้งที่ต้องให้เจ้าตัวตัดสิน
**จังหวัดที่อยู่** — พรอมต์เขียนว่า "ฐานนครปฐม" แต่ `README.md` ของ repo (หน้าโปรไฟล์สาธารณะ) เขียนว่า "อยู่จังหวัดสมุทรสงคราม"
เรซูเม่ทั้งสองฉบับใช้ **นครปฐม** ตามพรอมต์ไปก่อน เพราะเป็นข้อมูลที่ให้มาสด ๆ กว่า
เรื่องนี้กระทบจริงเพราะบริษัทใช้ระยะทางคัดคนออกรอบแรก — ถ้าสมุทรสงครามถูก ต้องแก้เรซูเม่ 2 จุด (หัวเรซูเม่ ไทย/อังกฤษ) และควรแก้ README ด้วย

## ข้อจำกัดของสภาพแวดล้อมที่รันรอบนี้ (ของจริง ไม่ใช่ข้อผิดพลาดชั่วคราว)
เซสชันนี้อยู่หลัง egress proxy ที่อนุญาตเฉพาะ API ของ Anthropic, package registry และ git
**โดเมนเว็บหางานถูกปฏิเสธทั้งหมด** — ทดสอบแล้ว: `th.jobsdb.com`, `www.jobthai.com`, `startup.jobs`, `freehire.me` และแม้แต่ `example.com` คืน `CONNECT tunnel failed, response 403`

ผลที่ตามมาต่อรูทีน
- ✅ ค้นประกาศได้ (ผ่าน web search)
- ❌ เปิดหน้าประกาศเพื่ออ่าน requirement เต็ม / ยืนยันวันที่ลงประกาศ / ดูช่องทางสมัคร — ทำไม่ได้
- ❌ ตรวจว่าประกาศยังเปิดรับอยู่หรือปิดแล้ว — ทำไม่ได้

ถ้าต้องการให้รอบอัตโนมัติทำงานเต็มที่ ต้องเปิด allowlist ของ environment ให้ครอบคลุม
`th.jobsdb.com`, `www.jobthai.com`, `www.jobbkk.com`, `www.jobth.com`, `www.linkedin.com`, `www.ismtech.net`
(ตั้งที่ environment ของ Claude Code บนเว็บ — ดู https://code.claude.com/docs/en/claude-code-on-the-web)
ระหว่างที่ยังเปิดไม่ได้ ทุกใบต้องเปิดยืนยันจากเครื่องตัวเองก่อนกดสมัคร
