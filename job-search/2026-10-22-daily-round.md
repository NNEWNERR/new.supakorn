## 1) สถานะการค้นประกาศ: **วันนี้ไม่มีของใหม่ที่ยืนยันได้**

ไม่ใช่เพราะไม่มีงาน แต่เพราะ **ค้นแล้วเปิดประกาศไม่ได้**

environment ที่รูทีนนี้รันอยู่ บล็อกการเปิดเว็บประกาศงานทุกแหล่งในลิสต์ที่กำหนด
พร็อกซีตอบ `403 Forbidden` ที่ชั้น CONNECT ก่อนถึงตัวเว็บ ทดสอบแล้วทั้ง:

| แหล่ง | ผล |
| --- | --- |
| th.jobsdb.com | 403 (บล็อก) |
| linkedin.com | 403 |
| jobtopgun.com | 403 |
| workventure.com | 403 |
| jobs.blognone.com | 403 |
| techsauce.co | 403 |
| glassdoor.com / monster.co.th / indeed | 403 |
| jobgether / remoterocketship / himalayas (remote ต่างประเทศ) | 403 |

ที่ใช้ได้มีแค่ **ผลสรุปจาก search engine** ซึ่งให้ชื่อบริษัทกับลิงก์ แต่ให้สิ่งที่จำเป็นต่อการคัดไม่ได้เลย คือ

- วันที่ลง/อัปเดตประกาศ → เช็กเกณฑ์ "ภายใน 7 วัน" ไม่ได้
- รายการ requirement เต็ม → ให้คะแนนความตรง 1-5 อย่างซื่อสัตย์ไม่ได้ และเช็กเกณฑ์ตัดทิ้ง (ขอ 3 ปีขึ้นไป / ขอเครื่องมือที่ไม่มีเกินครึ่ง) ไม่ได้
- มีทีมหรือแผน automation ไหม → ติดป้ายเขียว/เหลือง/แดงให้ระดับ B ไม่ได้

ตามกติกา "ห้ามขุดประกาศเก่าหรือประกาศไม่ตรงมาใส่ให้ครบโควตา" และ "ประเมินความตรงอย่างตรงไปตรงมา"
จึงไม่ออกตารางประกาศวันนี้ **ใส่คะแนนไม่ได้ก็ไม่ใส่** ดีกว่าใส่ตัวเลขที่เดามา

## 2) รอบพฤหัส — ตามผลใบที่ส่งเกิน 7 วัน

**ไม่มีอะไรให้ตาม เพราะยังไม่มีใบไหนถูกส่ง**

ตรวจกล่องจดหมายส่งออกของ newnertg@gmail.com ย้อน 60 วัน: **ว่างเปล่า ศูนย์ฉบับ**
เมลขาเข้าช่วงเดียวกันมีแต่

- เมลแนะนำงานอัตโนมัติจาก Jobtopgun ทุก 1-2 วัน ซึ่งแนะนำ **IT Support / Helpdesk / Service Desk / Application Support** แทบทั้งหมด — ไม่มี QA เลยแม้ตำแหน่งเดียว
- เมลแจ้ง CI พังจาก GitHub

นี่คือเรื่องสำคัญที่สุดของรอบนี้ ไม่ใช่เรื่องหาประกาศไม่เจอ เป้าคือสัปดาห์ละ A 3 B 2
ถ้า 60 วันส่งศูนย์ใบ ตัวเลขที่ขาดไม่ใช่ประกาศ แต่เป็นการกดส่ง

**ผลพลอยได้ที่ควรแก้:** โปรไฟล์ Jobtopgun กำลังถูกอ่านว่าเป็นสาย IT Support
ระบบ matching ของเขาเห็นอะไรในโปรไฟล์คุณถึงยิง Helpdesk มาให้ตลอด — หัวข้อโปรไฟล์กับ keyword ในนั้นน่าจะยังไม่ใช่ QA
แก้จุดนี้ 15 นาที ได้ feed ที่ตรงขึ้นทุกวันโดยไม่ต้องค้นเอง

### 3.1 ตัวเลขในบรีฟไม่ตรงกับ repo จริง — ต่ำกว่าความจริงมาก

กติกาบอกว่าตัวเลขต้องมาจาก repo จริงเท่านั้น ผมอ่าน README ของ `new.supakorn` แล้วเทียบให้

| Page Object | 6 | **10** |

ถ้าเรซูเม่ยังเขียน 24 tests / 6 POM อยู่ แปลว่ากำลังขายตัวเองต่ำกว่าของจริง 15 เท่า
**ไปแก้ตัวเลขในเรซูเม่ให้ตรง repo ก่อนสมัครที่ไหนทั้งนั้น** — นี่คือการแก้ที่ได้ผลที่สุดต่อเวลาที่ใช้

### 3.2 CI แดงอยู่ ตามอีเมลแจ้งเตือน

`NNEWNERR/Krungthon-Air-QA` ส่งเมล run failed ซ้ำ ๆ: 5, 7 (3 ครั้ง), 9 และ 16 ต.ค. ทั้ง `Krungthon Air QA — Playwright` และ `Daily Soak — Sprint 1 EXPAND`
ตัวล่าสุด 16 ต.ค. เป็น PR run `ci: run 7 read-only projects that were never in CI (+12 tests)`

ผมเปิด repo นั้นตรวจไม่ได้ (เป็น private และอยู่นอกขอบเขตที่ session นี้เข้าถึง) จึงยืนยันสถานะล่าสุดแทนคุณไม่ได้
แต่ประเด็นคือ **เรซูเม่เวอร์ชัน A ขาย "CI ที่รันจริง" กับ "daily soak" เป็นจุดขายหลัก**
ถ้ากรรมการกดเข้าไปเจอแดง จุดขายนั้นกลายเป็นหลักฐานตรงข้ามทันที
และคำถามสัมภาษณ์ "จัดการ flaky test ยังไง" จะถูกถามบนของจริงที่กำลังแดงอยู่

ตรวจเองก่อนส่งใบ ถ้าแดงเพราะ env ไม่พร้อม นั่นแก้ได้ด้วยกติกา skip-instead-of-fail ที่คุณเขียนไว้ใน README อยู่แล้ว

### 3.3 จังหวัดไม่ตรงกัน

บรีฟว่าฐานนครปฐม README เขียนสมุทรสงคราม คนละจังหวัด ห่างกันพอที่จะเปลี่ยนคำตอบเรื่อง on-site
เลือกให้ตรงกันทั้งเรซูเม่ โปรไฟล์ และ README เพราะ recruiter ใช้ข้อนี้คัดรอบแรก
